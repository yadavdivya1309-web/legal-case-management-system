
# Legal Case Management System

A web-based application built to manage legal clients and cases efficiently.

## Features
- Add, edit, and delete client records
- Add, edit, and delete legal cases
- Search cases by case number, title, or client name
- Filter cases by status
- Form validation
- Dashboard for case and client information
- MySQL database integration

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## How to Run Locally
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into `C:\xampp\htdocs\`.
4. Create the required database using phpMyAdmin.
5. Configure the database connection in `config/db.php`.
6. Open `http://localhost/legal-case-management/` in your browser.
